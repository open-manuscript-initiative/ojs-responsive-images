# PKP Responsive Images

Responsive image optimization plugin for PKP applications.

Supported platforms:

- OJS 3.5.x
- OMP 3.5.x
- OPS 3.5.x

## Features

- Responsive srcset generation
- WebP conversion
- AVIF conversion
- Manifest-based caching
- Incremental optimization
- Background optimization via cron
